# simple-messanger-webpack
Простой web-мессенджер, разрабатываемый в контексте лабораторных работ. Архитектура микрофронтендов.

Как запустить?

Установка:

### Настройка конфигурации:

npm i
cd packages/build-config
npm i
cd ../shared
npm i


### Настройка и запуск сервисов 


Для каждого сервиса ,в отдельных терминалах, /services выполняем:

npm i 
npm start


Вуаля. Надеюсь ничего не упустил.
